## Device checklist

1. Open Play full screen. Open the game's Menu and return with Back. Leave
   enlarged play with the host's visible control, then re-enter. Both controls
   must be independently reachable.
2. Start New Game with eight kingdoms. Enter a name using the visible keyboard,
   choose an emblem and create the campaign. Check the founding save feedback.
3. Tap a location, close its inspector, drag the map and pinch in/out. Releasing
   either gesture must not accidentally select a place. Tap another location
   after zooming, use Recenter, enter a region and return to World Map.
4. At the owned headquarters, use Armies → Orders → People → Households. Review
   Form Household with missing selections: read its reason and return with Back.
   Review Invite Apprentice, confirm it, and check the new person and 20-Gold cost.
   Inspect Career, Mentor and Succession; unavailable choices must explain why.
5. Recruit a formation into a second local army. End Turn, tap Pause during a
   rival phase, then transfer a formation or person between local armies. Use
   Step and Resume and confirm the next season advances once.
6. Review a route, back out, then confirm a legal move. Inspect a local threat
   expedition and its battle report if available. Page report/history rows and
   return through the visible Back/Close controls.
7. Open Help and page through the map, career and household topics. Text and
   navigation must remain separate at the supported size.
8. Make at least six distinctly named manual saves to exercise catalogue paging.
   Load a chosen test save; return to the title and Continue. Check map picking
   and the restored name/season after each load.
9. Open the same game in a second browser tab while the first owns the save
   writer. Check the visible storage-busy/retry route. Close the first tab, retry
   in the second, and confirm that saving succeeds without replaying an order.
10. Repeat location selection after changing the browser/window size or display
    scale when supported by the device. Report any clipping, tiny targets,
    unintended page scrolling, wrong picks, lag or lost saves.
